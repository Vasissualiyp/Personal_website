Cosmolunch Talk, August 2025

    COSMOLUNCH TALK

    AUGUST 15, 2025

    Title: Reproducible astrophysics with Nix

    Abstract: Science must be easily reproducible, but very often the software stacks that scientists use isn't. There were many attempts to solve this issue (Docker, Conda, HPC modules, etc.), but many of them aren't always the best for long-term reproducibility across systems. In this talk, I will introduce Nix: a paradigm in software packaging, including a language, a package manager, and an operating system. This paradigm guarantees atomic, almost bit-identical environments by isolating every dependency through cryptographic hashing. I will talk about philosophy behind Nix, provide examples of usage, advantages over traditional packaging methods, and conduct an optional live demo where we will try to run real astrophysics code using Nix.
